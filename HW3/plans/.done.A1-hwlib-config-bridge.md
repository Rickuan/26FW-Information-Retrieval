## 2. hw_bridge 對外介面（給組員參考）

hwlib 只能經由 `rag.hw_bridge` 使用。所有 hwlib 呼叫都轉向 stdout → stderr；
generator 只在推進 hwlib 時轉向，呼叫端在迴圈中 print 的內容仍寫到 stdout。

| 函式 / 類別 | 說明 |
|---|---|
| `iter_documents(warc_path, limit: int \| None = None) -> Iterator[tuple[int, str, str, str]]` | `(docid, trec_id, url, cleaned_text)`，WARC 順序；docid = TREC-ID 尾碼；空文字仍產出；`limit` 算產出篇數 |
| `iter_raw_records(warc_path) -> Iterator[bytes]` | 原始 record bytes，依序串接 = 原檔 |
| `inspect_targets(warc_path, trec_ids: set[str]) -> dict[str, TargetInfo]` | 只讀一次 WARC、只清理目標；找不到的 id 不在結果中；全部找到即停止 |
| `TargetInfo(docid: int, content_type: str, cleaned_text: str \| None)` | frozen dataclass；content_type 小寫、去參數、缺少時 `"(none)"`；hwlib 排除該文件時 `cleaned_text is None` |
| `preprocess(text: str) -> list[str]` | stop+stem term 序列；模組層級單例（第一次呼叫時建立） |
| `build_lexical_index(warc_path, index_dir, limit=None) -> dict` | 寫出 lexicon/postings/doc_map/metadata（metadata 最後寫），之後做 docid 連續性檢查；回傳 `{N, vocab_size, total_tokens, avg_doc_len}` |
| `build_doc_norms(index_dir) -> None` | ltc norms（`doc_norms.bin` + meta） |
| `load_ranker(index_dir) -> Ranker` | 建構時檢查 preprocessor 設定並立即 `get_norms("ltc")` |
| `Ranker.N: int`、`Ranker.search(terms: list[str], k: int) -> list[tuple[int, float]]` | ltc.ltc 自由文字；依 `(-round(score,6), docid)`；空 terms 或全部 df=0 回傳 `[]` |

**`rag.config`**（2026-11-26 討論後修訂，規格 1.3）

| 函式 / 類別 / 設定 | 說明 |
|---|---|
| `load_config(config_path=CONFIG_PATH, local_path=LOCAL_CONFIG_PATH) -> dict` | 讀 config.toml，再以 config.local.toml 逐鍵覆寫；`[corpus]` 為絕對 `Path`，`[paths]` 保留相對路徑字串 |
| `get_config() -> dict` | 預設兩個檔案，整個 process 只讀一次，回傳深複本 |
| `paths(fixtures: bool, cfg=None) -> dict[str, Path]` | 正式產物用 `paths(False)` = `HW3/<rel>`；fixtures 用 `paths(True)` = `HW3/<fixtures_dir>/<rel>`；兩套由同一份相對路徑計算 |
| `require_build_done(build_meta_path) -> dict` | 傳入 `paths(...)["build_meta"]`；檔案不存在、無法解析或 `status != "done"` 時 raise，否則回傳 build_meta |
| `ConfigError(ValueError)`、`BuildNotDoneError(RuntimeError)` | 設定不合法 / 建置未完成 |
| `HW3_ROOT`、`CONFIG_PATH`、`LOCAL_CONFIG_PATH` | 路徑常數 |
| `[runtime] use_fixtures`（預設 false） | 只寫在 config.local.toml；query、eval 以 `paths(cfg["runtime"]["use_fixtures"])` 取路徑；build 不讀它（看 `--limit`） |

規則：config.local.toml 不得覆寫 `[embed]`、`[paths]`、`[[inject.tokens]]`（raise `ConfigError`）；
`[paths]` 只能是 `HW3/` 底下的相對路徑，且 `fixtures_dir` 以外的路徑不得位於 `fixtures_dir` 之內
（不會出現 `fixtures/fixtures/...`）；`use_fixtures` 必須是布林值。

## 3. 架構重點

- config：`config.toml` ← `config.local.toml` 逐鍵覆寫（dict 遞迴合併，其他值整個取代）；
  覆寫檔含 `[embed]`、`[paths]` 或 `[[inject.tokens]]` 時 raise `ConfigError`。路徑以 `HW3/` 為基準，與 CWD 無關。
- build_lexical_index 重現 HW1 `run_build` 核心：`Indexer(spimi=False)` 逐篇 `add_document`
  → `write_binary_format` → `write_doc_map` → `write_metadata`；不用 `build()`、`write_all()`。
- 資料夾不預先建立：由需要它的程式在執行時建立（`IndexWriter` 會自動建立 index_dir）。

## 4. 決定與理由

- **D1 依賴版本**：全部以 `==` 鎖定；hwlib 依賴與根目錄 `uv.lock` 相同，LangChain 系沿用 VERIFY-14；
  numpy 2.5.4（根目錄 lock 的版本）。
- **D2 charset-normalizer==3.5.2**：bs4 的編碼偵測會使用它，結果隨版本改變。自動解析出的 3.5.3
  讓 29 篇文件解碼不同（vocab +241、tokens +451），索引與 HW2 不再逐位元組相同；
  鎖定 3.5.2（根目錄環境版本）後一致。理由也記在 `pyproject.toml` 註解與 `hwlib/README.md`。
- **D3 `limit < 1` 一律 raise ValueError**（HW1 的 `--limit 0` 代表不限制，這裡不沿用，避免語意含糊）。
- **D4 路徑用 normpath、不用 resolve()**：不跟隨 symlink，`source_warc` 維持在 `HW3/dataset/` 底下。
- **D5 config.toml 不含 `[inject] baseline_lexicon`**（使用者指示，將自規格刪除）；
  `[inject]` 只剩 `[[inject.tokens]]`，故不另寫空的 `[inject]` 表頭。
- **D6 `src/rag/__init__.py`**：新增空檔，rag 成為一般套件（原本以 namespace package 運作）。
- **D7 build_lexical_index 不清除 index_dir 內既有檔案**：殘留的舊 norms 會在 Ranker 載入時被
  sha256 檢查擋下。
- **D8 移除 `iter_record_content_types`**：改由 `inspect_targets` 用於手動挑選與驗收埋入目標
  （不再有 inject 程式；一次取得 content_type 與清理後文字），前者已無用途。
- **D9 `inspect_targets` 在全部目標找到後提前停止**；仍只讀一次。
