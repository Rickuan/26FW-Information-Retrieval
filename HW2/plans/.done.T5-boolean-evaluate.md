# T5 Boolean 求值引擎規劃

## 1. 目標
實作 `HW2/src/boolean.py` 之 `evaluate(node: Node | None, reader: IndexReader) -> set[int] | None`，遞迴求值 AST 產生布林候選 docID 集合，供下游 T6 VSM 排序使用。自由文字不作過濾回傳 `None`，布林與複雜查詢回傳 `set[int]`。

## 2. 上游依賴與接口
- **T1/T3 `writer.py`**：`reader.N`、`reader.df(term)`、`reader.get_doc_tf(term) -> (docs, tfs)`、`reader.get_postings(term)`
- **T4 `parser.py`**：AST dataclass 節點（`Term`, `Phrase`, `Near`, `Wildcard`, `Soundex`, `Not`, `And`, `Or`, `Node`）
- **T4b `positional.py`**：`position_match(node: Phrase | Near, reader) -> set[int]`
- **M5 `skip_builder.py`**：精簡後導入 `HW2/src/`，提供 `build_skip_list`、`intersect_basic` 與 `intersect_with_skips`

## 3. 前置技術決策與求值語意
- **公開入口防呆**：
  - 輸入 `node is None` 時回傳 `None`（空 query 或全 stopword 查詢情境）。
  - 根節點為 `Term`（`is_root=True`）回傳 `None`，代表自由文字查詢（不過濾），由 T6 依詞項自然召回。
  - 其餘所有節點委派給內部遞迴求值 `_eval(node, reader)`，一律回傳 `set[int]`。
- **內部節點求值規則 (`_eval`)**：
  - **`Term(tokens)`**：
    - 多詞代表隱含 AND；若 `tokens` 為空回傳 `set()`。
    - 任一 token 之 df == 0 或無 postings 時，立即 short-circuit 回傳 `set()`。
    - 單詞直接轉 `set(docs)`；多詞依 df 遞增排序後，呼叫 `intersect_with_skips` 兩兩交集。
  - **`And(children)`**：
    - 遞迴求值所有子節點得到 `set[int]` 串列；依集合大小由小到大排序後依序取交集。
    - 任一步驟集合為空則立即提早 short-circuit。
  - **`Or(children)`**：
    - 遞迴求值所有子節點，取所有候選集合之聯集（`set.union`）。若無子節點回傳 `set()`。
  - **`Not(child)`**：
    - 遞迴求值 child 得到子集 $S$；以全集 `set(range(reader.N))` 扣除 $S$ 回傳差集。
  - **`Phrase` 與 `Near`**：
    - 呼叫 `positional.position_match(node, reader)` 取得符合位置約束之 doc 集合。
  - **未展開節點防呆**：
    - 輸入必須經 `expand`；若遇 `Wildcard` 或 `Soundex` 節點，直接拋出 `ValueError`。

## 4. 自包含架構與加分項接口
- **自包含精簡導入**：引入 `HW1/src/skip_builder.py` 至 `HW2/src/skip_builder.py`，移除全記憶體 Indexer 與未用型別依賴。
- **純整數 docID 適配**：提供包裝函式建構 `PostingWithSkip`（或直接自整數串列建置 skip），對齊 `get_doc_tf` 回傳之整數 docs。
- **比較次數驗證接口（加分 5）**：在模組內保留 `intersect_postings(docs1, docs2, use_skip=True) -> tuple[list[int], int]`，以利測試驗證比較次數對照（skip < basic）。

## 5. 測試策略 (`HW2/tests/t5.test.py`)
- **小語料 Mock Index**：建立輕量 `MockIndexReader`（N=10，預設 postings），無需依賴大磁碟即可秒級跑完測試。
- **節點求值覆蓋**：
  1. 根節點 Term 回傳 None；內部 Term 回傳全部 tokens 的 doc 交集。
  2. And 多子節點交集、short-circuit 空集合判定。
  3. Or 多子節點聯集。
  4. Not 反向差集、純 NOT 查詢（如 `NOT linux`）。
  5. Phrase 與 Near 位置比對整合呼叫。
  6. 巢狀複雜布林運算（如 `(A OR B) AND (C OR NOT D)`）。
  7. 邊界與例外防呆（`node is None` 回傳 None、未 expand 的 Wildcard / Soundex 拋錯）。
  8. 加分項驗證：對照 `intersect_postings` 之線性 vs skip 比較次數。
