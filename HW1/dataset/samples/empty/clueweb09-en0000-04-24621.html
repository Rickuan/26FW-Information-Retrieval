In order to utilize all the features of this Web site, JavaScript must be enabled in your browser. Please follow the instructions below to activate JavaScript on your computer.

Internet Explorer 5.0+ for Windows

    1. On the Tools menu click Internet Options
    2. Click on the Security tab at the top of the dialog
    3. Click on the Custom Level button
    4. Scroll towards the bottom of the list in the Security Settings dialog
    5. Make sure Active Scripting is enabled
    6. Click OK button to save the settings
    7. Refresh the page

Netscape Navigator 6.0+ for Windows

    1. On the Edit menu click Preferences
    2. On the left side of the dialog, click on the box next to Advanced
    2. If present (version 7.0+) click on Scripts & Plugins
    3. Select the Enable JavaScript for Navigator checkbox on the right
    4. Click the OK button to save the settings
    5. Refresh the page

Safari for Mac OS X

    1. On the Safari menu, click Preferences
    2. Click on the Security button at the top of the dialog
    3. Select the Enable Javascript checkbox
    4. Close the dialog
    5. Refresh the page

Internet Explorer for Macintosh

    1. On the Explorer menu, click Preferences
    2. Under Web Browser, click Web Content
    3. In the Active Content Area, select the Enable Scripting checkbox
    4. Click the OK button to save the settings
    5. Refresh the page
