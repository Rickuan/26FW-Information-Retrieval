## 1. 資料結構與設計規範

```python
@dataclass(slots=True)
class SkipPointer:
    target_doc_num: int
    target_index: int

@dataclass(slots=True)
class PostingWithSkip:
    doc_num: int
    tf: int
    positions: array            # 引用 M3 Posting.positions（array('I')），不額外複製
    skip: SkipPointer | None = None
```

- **間隔策略**：$L = \lfloor\sqrt{P}\rfloor$；門檻 $P < \text{MIN\_SKIP\_LEN} = 9$ 時不建立 Skip 指標（維持 `skip = None`）。
- **跳躍指標位置**：僅在 index $0, L, 2L, \dots$ 且滿足 $i + L < P$ 時建立；帶 skip 的節點數嚴格等於 $\lfloor(P - 1) / L\rfloor$。
- **指標目標**：`target_doc_num = postings[i + L].doc_num`，`target_index = i + L`。

## 3. 與原計畫的差異與設計決策

| 項目 | 原計畫 | 現行實作 | 理由 / 設計決策 |
|---|---|---|---|
| 🔄 執行模式 | — | 僅全記憶體模式；SPIMI 模式略過提示 | AND 查詢需走訪記憶體 postings；SPIMI 模式建完後記憶體 index 為空 |
| 🔄 記憶體引用 | `list[int]` 複製 | 引用 `Posting.positions`（`array('I')`） | 1,183 萬筆 posting 避免額外數 GB 記憶體複製開銷 |
| 🔄 skip 節點數公式 | `floor(P / L)` | `floor((P - 1) / L)` | 當 $P=9, L=3$ 時只有 index 0, 3 可建 skip（6+3 超界） |
| 🔄 跳躍形式 | 單次跳躍 `if` | Manning IIR Fig. 2.10 連續跳躍 `while` | 差距顯著時一口氣連跳多個間隔，顯著降低外層迴圈比較次數 |
| 🔄 比較次數計算 | 未明確定義 | 僅計入外層主迴圈 doc_num 數值比對 | skip 檢查視為指標移動導引，確保 skip 比對次數恆 $\le$ basic |
| 🆕 查詢詞正規化 | — | 整合相同配置之 `Preprocessor` | 大小寫折疊與字幹提取（如 `"Games"` 自動還原為 `"game"`） |
| 🆕 停用詞安全處理 | — | 經由 Preprocessor 清空時提示並回傳空交集 | 避免因停用詞被移除非預期報錯 |
| 🆕 隨需建置介面 | 僅全量建置 | 額外提供 `build_term(term, indexer)` | 方便單一詞組或互動查詢隨需建置 skip list |

## 4. 演算法細節與參考實作

**連續跳躍交集演算法**（Manning IIR Fig. 2.10 標準）：

```python
def intersect_with_skips(
    p1: list[PostingWithSkip],
    p2: list[PostingWithSkip],
) -> tuple[list[int], int]:
    result: list[int] = []
    i = 0
    j = 0
    n_comparisons = 0
    len1 = len(p1)
    len2 = len(p2)

    while i < len1 and j < len2:
        n_comparisons += 1
        d1 = p1[i].doc_num
        d2 = p2[j].doc_num

        if d1 == d2:
            result.append(d1)
            i += 1
            j += 1
        elif d1 < d2:
            skip = p1[i].skip
            if skip is not None and skip.target_doc_num <= d2:
                while p1[i].skip is not None and p1[i].skip.target_doc_num <= d2:
                    i = p1[i].skip.target_index
            else:
                i += 1
        else:
            skip = p2[j].skip
            if skip is not None and skip.target_doc_num <= d1:
                while p2[j].skip is not None and p2[j].skip.target_doc_num <= d1:
                    j = p2[j].skip.target_index
            else:
                j += 1

    return result, n_comparisons
```
