## 4. 格式規範與參考實作

**作業規定文字格式**（投影片 p.9 Fig. 2.11）：
```python
def format_line(term: str, plist: list[Posting]) -> str:
    body = "; ".join(f"{p.doc_num}, {p.tf}: <{', '.join(map(str, p.positions))}>" for p in plist)
    return f"{term}, {len(plist)}: <{body}>\n"
```
> 解析時以第一個 `", "` 切出 term（容許 term 內部含逗號但無空格，例如 `"10,000"`）。

**二進制 Block 格式**（`postings.bin`）：
```
[df: uint32 BE][Δdoc_num: VByte][tf: VByte][n_pos: VByte][Δpos...: VByte]...
```
- 首筆 `doc_num` 與各 posting 首個 `pos` 均以 0 為基準計算 Delta。

## 5. 工項與 AC 完成狀態

| Step | 功能 | 關鍵 AC（全數通過 ✅） |
|---|---|---|
| **4-A** | 作業規定文字格式 | `dictionary.txt` 嚴格字典序；`postings.txt` 每行 df == posting 數、tf == positions 數，抽查與 indexer 完全一致 |
| **4-B** | 元資料 JSON | `metadata.json`（含 spimi）與 `doc_map.json`（key 為字串化 doc_num）schema 完整，項目數 == N |
| **4-C** | VByte 壓縮 | `encode(300) == b'\xac\x02'`；0, 1, 127, 128, 300, 16383, 16384 等 round-trip 全數成立 |
| **4-D** | 二進制索引 | `encode_postings_block` / `decode` round-trip 正確；`postings.bin` 壓縮率 35.5% < 60%；lexicon 行數 == vocab |
| **4-E** | IndexReader | lazy-load lexicon，seek + decode 回傳 `list[Posting]` 與 `DocEntry`；抽查與 Indexer 逐筆吻合 |
| **4-F** | 單次走訪寫檔 | `write_all()` 產物與獨立呼叫逐 byte 相同；SPIMI 與全記憶體輸出逐 byte 相同 |

## 6. 對外介面

```python
class IndexWriter:
    def __init__(self, output_dir: str | Path) -> None: ...
    def write_all(self, indexer: Indexer, config: dict | None = None) -> None: ...  # 主程式首選
    def write_dictionary(self, indexer: Indexer) -> None: ...
    def write_postings_text(self, indexer: Indexer) -> None: ...
    def write_binary_format(self, indexer: Indexer) -> None: ...
    def write_metadata(self, indexer: Indexer, config: dict | None = None) -> None: ...
    def write_doc_map(self, indexer: Indexer | dict[int, DocEntry]) -> None: ...

class IndexReader:
    def __init__(self, output_dir: str | Path) -> None: ...
    def get_postings(self, term: str) -> list[Posting]: ...  # positions 為 array('I')
    def get_doc(self, doc_num: int) -> DocEntry | None: ...
    def get_metadata(self) -> dict: ...
    def vocab_size(self) -> int: ...
    def __contains__(self, term: str) -> bool: ...
```

### 注意事項
1. **串流走訪**：寫檔一律使用 `indexer.iter_postings()`；全記憶體驗證抽查使用 `indexer.get_postings(term)`。
2. **型別一致**：`Posting.positions` 為 `array('I')`；寫文字用 `", ".join(map(str, p.positions))`，比對或轉 JSON 前需 `list()`。
3. **M5 整合點**：若 M5 Skip pointer 啟用二進制擴充，可在 postings block 內額外序列化 skip offset。
